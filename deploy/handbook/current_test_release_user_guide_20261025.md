# 驻马店重大风险防控测试版使用说明

适用20261025-r4-dual-machine，更新日期2026-10-25。当前为供测试的版本，原天津所有模块的完整对照还在进行。

## 电脑端

1. 打开 https://www.joinlinksmart.com/zhumadian/ 。项目名称应显示“驻马店重大风险防控”，使用已有测试账号手工登录，按页面填写验证码；账号和密码由既有账号管理方提供，不写入本说明。
2. 进入原组件首页后，系统导航包含安全风险智能管控平台、敏捷应急管理、敏捷应急指挥等入口；快捷链接包含双重预防、智能巡检、特殊作业、重大危险源、应急处置、我的待办。实际菜单由角色权限决定，不承诺所有账号看到相同内容。
3. 按模块进入页面，逐项检查列表、筛选、详情、表单、导入导出、附件和流程是否与天津原站一致。新增、修改、提交、审批等只在明确测试范围内操作，填写可辨识的测试记录；已有业务资料不要删除或覆盖。
4. 当前只确认已登录首页及三维入口可操作，不能仅凭菜单存在认为列表、审批或全部接口通过；问题反馈应包含入口、模块、操作步骤、时间、提示和预期结果，不发送账号密码或验证码。

## 250和252的敏捷应急指挥

公网业务系统与本机三维是两个运行部分。两台电脑都从同一公网首页进入，但链接中的127.0.0.1指当前操作电脑，不能替换为另一台电脑的IP。

252恢复后的操作：

1. 使用前先确认本机三维服务窗口仍在运行。机器重启后需要手工启动时，双击一次【F:\XNBY\ZhumadianScene_20261020\2_启动本地应急三维.lnk】。不要重复启动。
2. 保留“驻马店本地应急三维 - 关闭此窗口停止服务”窗口，可以最小化；关闭它会停止本机服务。当前没有配置开机自动启动。
3. 返回公网首页，点击左侧“敏捷应急指挥”。新标签应打开 http://127.0.0.1:8767/?topic=emergency&mode=command 。若此前标签停在拒绝连接页，服务就绪后刷新该页即可。
4. 检查标题“驻马店·敏捷应急指挥”、地景、14家企业与全部16个标注。可以使用总览、斜视、近景和企业标牌浏览；图层为已有资料点位，并不等于实时业务统计。

250当前服务已验证可用，保持运行即可；它的安装位置与252不同，不使用上述F盘入口。三维编辑保存属于独立编辑器功能，本说明的三维网页浏览不会自动回写原用户DLG。

## 手机网页

在手机浏览器打开 https://www.joinlinksmart.com/zhumadian/h5/ ，使用已有账号手工登录并按原页面操作。当前H5页面和登录配置接口已可访问，手机真机的登录、巡检、隐患上报、附件、审批和电脑端数据一致性尚待逐项验收；不宣称这些流程都已通过。APK尚未交付。手机中的127.0.0.1指手机自身，不会自动连接250/252的三维服务，当前双机本地三维入口适用上述两台Windows电脑。

## 常见问题

| 现象 | 首先检查与处理 |
| --- | --- |
| 127.0.0.1:8767拒绝连接 | 本机三维服务是否运行；252按上述既有快捷方式启动一次，然后刷新。已有服务或报错时不反复双击 |
| 公网能登录，但模块无权限 | 记录账号对应角色与模块名称，由权限管理方核对，不自行修改权限或重置原账号 |
| 页面仍显示旧名称/旧图标 | 确认是/zhumadian/入口，电脑按Ctrl+F5刷新；记录具体页面，继续核查缓存与资源版本 |
| 页面出现数据/接口错误 | 记录模块、时间、操作和提示，由开发核对前后端及测试数据，不重复提交同一审批 |
| 三维局部仍粗或加载等待 | 与连接故障区分，反馈视角和等待时间；全区20秒外围清晰度仍未验收 |

当前版本事实与尚未完成项见[验收矩阵](current_test_release_acceptance_20261025.md)。本次公网入口上线、双机可用不等于“全面复刻”阶段目标全部达成，完成后将另行通知正式复核。
