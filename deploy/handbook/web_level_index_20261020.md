# Web 端 LEVEL 索引、计划等待与驻留容量实验

更新：2026-10-20T22:38:56。状态：独立本机实验候选，源码及真实浏览器冒烟检查通过；完整地景加载验收尚未通过。完整 UE 效果效率、EXE 标注工具、Web 业务和迁移目标仍 active。

## 问题和实现

旧 Web 使用基础父层自己的 bbox 全量排序、截前 16，再直接驱逐其余驻留根；子孙几何可能伸出父 bbox，仍需要的外围根也会因排名截断退回粗层。本实验以显式 `levelIndex=1` 启用，默认页面选择策略保持原状。

1. 只读服务 `/api/level-index/status` 固定当前 manifest 身份，新增 `/api/level-index/files/index_manifest.json`、`root_index.json` 和 `tile_N.json` 三类精确路径。服务检查 ordinary 路径、大小与原始字节 SHA，不接收任意文件路径、查询参数、写入或来源转换。读取索引本身不创建构建任务或租约。
2. 浏览器依次校验状态、manifest SHA、root_index SHA 与每个实际读取 tile 的 SHA。全 2346 根、235107 可绘制节点均有封存记录，使用原始子孙几何并集的 AABB 建 BVH；相机完整六平面检索包含相切和近裁面穿越，不先截前 16。拓扑页按需读取，最多缓存 16 页并限制同时读取数。
3. tile 校验源 SHA/字节、唯一节点、完整可达父子树、深度与子孙范围。新增混合后代 antichain 完整性证明，但尚未把 v3 混合 cut 提交到 Web SourceFrontier，当前仍逐级完整直接子族。拓扑完整不能代替画面覆盖证明。
4. 16 个驻留槽仍保留，直接预算计划和分步恢复同时检查槽位及字节；仅在完整基础层可恢复且总损失满足现有 2 倍迟滞时退休较低收益根。失败不部分修改 live cut。细层 512 MiB、根包 384 MiB、单上传 32 MiB未提高；512 MiB并非整个浏览器显存。
5. Web 元数据计划请求带 `wait_ms=200`，仅收到精确 ACK=200 才省去额外 300ms 客户端等待；旧服务 400/422 拒绝可选参数后重试同原端点一次，继续旧退避。租约和实际页面仍独立申请；保留原 marker SHA、租约、取消及几何/纹理校验。

- owner shutdown 204，服务退出 0，reader closed；受保护写入 0、源构建失败 0、最终租约/排队/活动等待者均 0。

## 体验、部署与回滚

手动入口 `Application/实验入口/地景加载优化_20261020/启动Web索引实验.cmd`，未自动执行。使用候选包内私有 Python，读取同一已绑定原始 Data，回环地址随机端口；自动打开系统浏览器。每次保留独立 manual_runs 日志，关闭控制台/按 Ctrl+C 停止；最长 30 分钟自动关闭。该入口依赖当前本机目录，是实验入口，不是可搬迁正式安装器。

独立 package 仅从旧 W2 清单克隆 5840 个声明文件，不复制 GIS 或旧 UserData；仅 viewer.js 和 indexed_family_source.py 改变。试验自己的图层/SQLite 在自己的 UserData。旧 EXE、旧 Web QA、公网首页、252 安装与业务数据库未切换，原 14 个 held 修改未编辑/提交。回滚只需关闭实验服务并使用原入口，不修改正式发布指针。

首次启动控制器和私有 Python 没带 -B，生成未声明 pyc 被清单正确拒绝；已归档 startup_failure_bytecode 并禁字节码，未放宽清单。首轮浏览器因旧静态白名单没有索引文件路由报 404，记录 browser_initial_index_route_missing 保留；最终新增精确索引只读路由后通过。新 HTTP 测试曾引用错误审计字段，已改为 activeLeases 并通过；这些失败不并入成功记录。
