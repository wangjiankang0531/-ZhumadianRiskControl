# 屏幕区域剩余粗层优先级设计（实验）

2026-10-28。目标是改善镜头边缘迟迟停留在粗层的问题。沿用已验证的完整初始层选择，增加有限的区域剩余细节权重；仅在 QA 参数 regionResidual=1 且完整只读索引与原图能力绑定验证通过后启用。产品默认关闭。

利用现有96×44源ID/对数视深度采样，将未被面板遮挡的照片像素分入九格。几何P90边长和纹理P90世界尺寸投影形成代理质量量值 q=max(edgeP90,4*texelP90)*projectionScale/depth；q>6时残差log2(1+q/6)，缺少指标记未知。这里P90不是几何误差证明，代理阈值不代表人眼纹理验收。

采样中有粗层残差时，各格只观察粗层最大残差；否则观察所有来源。区域因子为平均照片样本数/本格样本数乘本格最大残差/各格残差均值，限在0.5至4；未知或零残差退回原有0.5至2的面积权重。遮挡像素仍0.2。该逻辑只改变优先顺序，不改拓扑、原子子族准入、格式边界、预算限额或资源像素。原始读回/密集诊断保持中性，不受该权重影响。

新9项行为检查覆盖粗层优先、细层接续、零残差、未知/隐藏、非法值、几何与纹理代理、输入不变和源ID重编号不变。本地846项及完整独立Web源码846项通过。
