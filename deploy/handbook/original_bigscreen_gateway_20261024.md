# 天津原大屏：独立网关与实际页面接入

本阶段沿用原页面、原业务后台、原管理平台及独立大屏后台，不改原界面或业务处理类。独立 127.0.0.1:18893 候选已实际运行并完成有限 UI/接口检查，随后正常关闭；未更新公网，完整复刻尚未验收。

## 真实验证范围

- 98 个构建产物（含根目录 worker）、原公共 logo 和运行 config 经真实 Nginx 逐字节/SHA 检查；原 public 直接只读引用，未再次复制静态资产。16 个原匿名默认 Mock 响应经同一网关逐字节一致，仍仅代表默认响应，不代表查询或写入行为。
- 原大屏后台在准确自有 12 KiB SQLite 副本上启动，原 main、SQLite 路径/Bean、单 DLL 绑定通过。协同双客户端增删和 HTTP→交互 WS 经实际网关通过；最后客户端退出按原实现清空自有副本，原库/用户 DLG 不变。
- 四个原导航页实际打开：安全一张图、应急一张图、指挥决策、可视化预案。只验证已观察到的页面与读取，未提交报送、广播、资源调度、视频控制、账号/验证码或业务修改。
- 原巡检接口 code=0，没有 success 字段；原 Service 拦截器按既有逻辑处理，不向响应补字段。年筛选结果 32 点位/1 任务/1 问题与页面一致；无筛选为 32/262/14。应急物资 162、队伍 4、专家 4 来自原业务接口；物资入口能打开 162 行原记录并关闭。消防水源 20 和视频 384 来自原静态 JSON，消防站点 1、卫生医疗 3 为原模板常量，均保持原实现，不能把七项都称为后台实时统计。
- 原 countTo 有两秒动画，中间数值不是最终统计。稳定后已核对 162/4/20/4/1/3/384；不以初始 0 或动画中间值判定数据缺失。列表对空类型显示“未分类”是原组件逻辑，未私自修改。
- 原三维区依赖 acapi.DigitalTwinPlayer 的 DTS 云渲染服务，原 isExlorer=false。没有用桌面 acex SDK、本机 8767 地景或假 API 冒充该接口。当前独立配置把未接通的渲染 SDK 显式指到自有 503 路径，中央三维区仍空，不能将本阶段记为完整三维大屏通过。

## 运行与停止

入口 tools/serve_original_bigscreen_candidate.py --help。显式提供已固定 SHA 的构建收据、16 默认响应收据及仍存活的原 PC/H5 联调 ready 收据。业务请求仍转发既有原业务网关 18891；独立大屏后台与 Mock 数据服务使用各自回环端口。四端口必须互不相同。候选租约 1–45 分钟，必须早于上游原业务候选结束至少 45 秒，不因超时重新启动，也不修改上游服务。

运行配置仅改变八项部署端点，保留其它原属性和云渲染分支；同一源配置再次生成与实际运行字节相同。非自有来源、带路径的 origin 和错误原配置 SHA 在输出目录创建前拒绝。页面连接限制为本机服务；Mock 转发配置去除 Authorization/Cookie/Referer，业务接口保持原响应及认证处理。Nginx 日志仅记方法和状态，不记路径、查询或凭据。

正常停止先关闭自有测试页，再写自有运行根 stop；控制器核对准确 Nginx owner PID 后 quit，关闭原 Spring 并核验 ContextClosed/退出 0，停止 Mock。若网关或后台强制终止、退出非零、ContextClosed 缺失、原库/原包不一致或控制器失败，必须判失败。最后的收紧判定用真实 j1/j2/j3 收据验证；与 j3 已执行 main 的启动、接线和停止 AST 完全一致，仅增加更严格的最终判定，不重复启动程序。

## 失败保留与真实缺口

j1 失败于自有目录入口文件 alias，导致 index.html 重复拼接；j2 失败于原根目录 worker 未挂载。两次网关/原后台均正常退出，失败记录保留。修正为编译根优先、原 public 只读回退后，j3 的全部 98 资源验证通过；j3 已正常关闭，不能再将旧 ready 文件当存活证明。

组合网关协议脚本的 WS 两段通过，但整体 failed：自有检查错误要求原响应 success=true。保留该失败，不改判全过；原始 code=0 语义及业务筛选结果另以只读 HTTP 核验通过。后续回归应分别判定原协议语义，不通过代理补造字段掩盖错误。

Y 盘原交付 dist 的配置和源码模板均为云渲染分支，服务/工程号一致，WS/Dify 端点有差异，不能把源码模板当原环境内存配置。原配置 SDK 地址的一次匿名只读探测从本机超时，不证明原服务器停机。Y 上已定位 Cloud/Explorer 两份 ISO 与原工程，合计约 8.8 GB，仅清点元数据，未校验镜像全内容、未复制/挂载/安装/启动，亦未改变共享或安全设置。

剩余工作为原渲染服务/SDK及许可配套接入、真实原账号与角色、PC/H5 全模块/业务写入流程/文件关联、历史对象、真机、252 与公网同版验收。现有 8767 三维和原 PC/H5 实例保持；完整 UE/EXE/Web/迁移及天津第一阶段目标均 active，fullCloneReady=false。
