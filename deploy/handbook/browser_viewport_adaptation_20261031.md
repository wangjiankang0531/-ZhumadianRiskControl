# 浏览器可用区域自适应规范

布局基准为浏览器视口的CSS像素宽、高。CSS视口单位、弹性布局、grid和clamp自动随窗口/缩放变化重排；不按物理显示器分辨率固定缩放整页。

首页R18以原南港模板及作用域样式为基准，在960—3840 CSS像素宽范围覆盖桌面导航布局。七组连续改变窗口尺寸的独立验证均通过：1536×704（1.25像素比）、1920×1080、1366×650、1280×600、1024×576、960×480、1920×880。九入口和二维码完整可见，菜单文字不截断，悬停装饰不拦截点击。宽度范围外沿用原断点，尚未全面验收。

图表后续按实际容器尺寸调整：增加容器尺寸观察，正尺寸时在动画帧调用图表resize，组件卸载时断开观察和销毁实例；保留页面激活后的尺寸恢复。布局需要为图例留出独立区域，并校验空数据、长名称及不同卡片宽度。现有ECharts组件仅监听window.resize，Chart3固定右侧图例在窄容器会挤压饼图；这些后续修正尚未纳入R18。

表格保留可读的最小列宽及合理滚动，长文本按业务需要换行/截断并提供完整信息；不得通过隐藏滚动条或遮挡内容制造单屏通过。高缩放、窄窗、超宽屏、实际角色菜单和切换侧栏都需验收，不能只检查启动时的一组尺寸。
