# R21工作流筛选公测步骤（待发布）

本步骤对应待发布R21，当前公网最近核验R19。收到“R21已部署并核验”的通知后再按此复测；G6记录字段未包含在本次修复中。

1. 正常登录驻马店网站，进入审批管理→待办事宜或我已处理。若人员条件折叠，点“更多”。
2. 点发起人员，使用原人员选择器搜索并选择一名有相关流程的人员，确认后点搜索。结果应按该人员筛选。
3. 改选其他人员并搜索，检查结果随条件变化；新的条件应从第一页开始。
4. 再次打开人员选择器，改选后点取消，原来已经确认的筛选条件应保持。
5. 用筛选框清除图标或重置，结果应恢复原权限范围；分页保留已确认筛选条件。
6. 我的发起始终仅含本人发起的流程：选择本人显示匹配流程，选择其他人员零条；清除/重置恢复本人流程。
7. 工作台任务表头“计划名称、状态、巡检时间”应保持完整单行，较窄卡片可正常横向滚动查看。

本机已用原SDK自建两普通角色/流程、真实编译整站验证；真实南港角色与业务数据仍请按各自原权限复测。不要向AI提供密码、验证码或业务原始记录。
