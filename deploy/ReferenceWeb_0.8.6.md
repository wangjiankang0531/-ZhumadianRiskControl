# 驻马店 WEB 0.8.6 参考业务模拟候选

这是基于天津系统只读学习及驻马店261013需求的阶段候选，并非全面等价系统验收。
本轮记录73条页面观察；各模块深层表单、八类作业差异、审批规则、真实IAM、实时监测/视频/通信及参考三维空白区域仍需继续验证。

## 测试机使用

将本文件夹完整放在 F:/XNBY/ReferenceWeb_0.8.6，打开其中“6_业务参考模拟版.lnk”。快捷方式复用 F:/XNBY/ZhumadianTest/Application/runtime/python/python.exe；保留原0.9.8安装，不覆盖原1至5入口。打开 http://127.0.0.1:8791/。
服务仅绑定127.0.0.1；不开放局域网或更改防火墙。启动时记录自身PID到work/server_process.json；重复启动只重用相同数据绑定服务，端口属于其它安装时拒绝，不终止旧进程。

三维/原门户链接为已有8767服务，需要先通过原2或3快捷方式启动原服务。本小包不含GIS、原DLG、生产数据库、凭据或新EXE。

## 功能与数据边界

当前82类目录（含驻马店需求扩展），初始984条合成样本。查询/企业和状态筛选/分页/详情/新增/顺序模拟流转/审计时间线、计划卡片、值班月历、按实际模拟记录聚合的统计可体验。
所有流程均为独立模拟，不等于参考系统业务规则或正式角色审批已验收。不要输入真实个人信息、生产业务或认证凭据。
模拟库在本目录 Assets/Demo/reference_demo.sqlite，重启保留新增与状态，种子不覆盖已修改记录；字段补齐追加审计。不修改原ZhumadianTest/Assets/DLG或BusinessData。

## 团队体验建议

1. 工作台进入隐患台账，企业/状态/关键字查询，下一页，打开详情，填写模拟处理说明并流转，重开确认版本及时间线。
2. 查看排查计划、巡检计划双列卡片。
3. 值班计划切换月份，模拟新增当前月份的一条排班，确认月历及重开保留。
4. 特殊作业统计、重大危险源统计、环境报表可回到对应台账核对总数和分组。
5. 浏览应急预案、响应、专家/队伍/物资及其它目录。记录与参考系统不同的字段/布局/状态规则，继续逐页完善。

停止进程或备份前检查本目录自身PID，不能据旧PID终止其它程序。运行中备份使用SQLite backup，或者正常停止后复制全部sqlite/WAL。MySQL和Apache迁移脚本只是准备阶段，未做真实环境验收。
